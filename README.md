# Data Directory

## RTK Points
Historical RTK coordinate table for 38 control points. Obtained from the technical note ["Spatial assessment of landslide risk using GNSS-based displacement analysis and a resident vulnerability index in northwestern Chilpancingo, Guerrero, Mexico"](https://link.springer.com/article/10.1007/s10346-025-02583-y). In RTK file get two CSV files: the [original data](https://github.com/joaquinsalas/chilpancingo_landslide/blob/main/Data/RTK/rtk_original_data.csv) from the technical note and the processed data from the code.

## ROI
ROI polygon in ESRI Shapefile format.
