# Data Directory

## RTK Points
Historical RTK coordinate table for 38 control points. Obtained from the technical note "Spatial assessment of landslide risk using GNSS-based displacement analysis and a resident vulnerability index in northwestern Chilpancingo, Guerrero, Mexico" 

## ROI
ROI polygon in ESRI Shapefile format.
