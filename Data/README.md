# Data Directory

This directory separates official external inputs from project-derived outputs.

- `NISAR/`: instructions and placeholders for six official NISAR Level-2 GSLC HDF5 products. These large files are not committed.
- `RTK/`: measurements transcribed from the cited 38-station RTK-GNSS study and code-derived tables. These are not raw receiver files.
- `ROI/`: the study-area polygon and its complete companion files.
